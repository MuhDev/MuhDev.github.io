# Mohammed Al-Attas | Portfolio 2026 v2

An award-winning, production-grade personal portfolio built for **Mohammed Al-Attas (محمد العطاس)** — Mobile App Engineer & UI/UX Designer.

Designed with Dark Obsidian glassmorphism inspired by **pszostak.pl**, engineered with **Apple Human Interface Guidelines** and **Emil Kowalski's Design Engineering** craft principles.

---

## 🌟 Key Features

1. **Dark Obsidian & Aurora Glassmorphism**:
   - Deep background base (`#09090d`) with subtle ambient glowing orbs.
   - Ultra-crisp frosted glass cards (`backdrop-filter: blur(20px)`) with hairline borders.
   - Dynamic kinetic shimmer typography on display headlines.

2. **First-Class Instant Bilingual Engine (Arabic & English)**:
   - Full RTL (Arabic with **Cairo**) & LTR (English with **Plus Jakarta Sans / Inter**).
   - Zero-reload reactive switching with state saved to `localStorage`.
   - Technical tags and telemetry powered by **JetBrains Mono**.

3. **Interactive Bento "Craft & Philosophy" Grid**:
   - Asymmetric Bento grid highlighting mobile architecture (Flutter, Clean Architecture, BLoC/Riverpod), UI/UX craft, cloud services, and global remote agility.

4. **Realistic Smartphone Mockups for Live Apps**:
   - Showcases real published apps (*Qaaf*, *AskUrDr*, *CashBack*, *Makarem*, *Special Offers*, and *Dribbble-to-Flutter series*).
   - Direct store badges (App Store, Google Play, GitHub, Uptodown).
   - Deep-dive case study modal with high-res screenshot galleries.

5. **Skills Radar & Credential Verification**:
   - Categorized skills matrix with crisp SVGs and FontAwesome 6 icons.
   - Bachelor's Degree in IT and verified Google AI Essentials certification with direct Coursera validation link.

6. **Tactile Micro-Interactions & Working Formspree Contact Form**:
   - Instant copy-to-clipboard email pill with Sonner-style toast notifications.
   - Formspree AJAX form integration with dynamic loading, success, and error feedback.
   - Apple-grade spring physics on buttons and interactive hover states.

## 🚀 How to Run Locally

You can open `index.html` directly in any modern browser, or run a local HTTP server:

### Option 1: Python HTTP Server (Built-in)
```bash
cd D:\projects\personal\profile_2026_v2
python -m http.server 3000
```
Then visit: `http://localhost:3000`

### Option 2: Node.js (npx serve)
```bash
cd D:\projects\personal\profile_2026_v2
npx serve -l 3000
```
Then visit: `http://localhost:3000`

### Option 3: VS Code / Cursor Live Server
Right-click `index.html` and click **"Open with Live Server"**.
